# Gestión documental — OneMore Consulting

Este directorio centraliza las normativas, metodologías y la planificación estratégica de OneMore Consulting. Reúne los documentos rectores que garantizan la calidad, la seguridad y la estandarización a lo largo del ciclo de vida de los proyectos.

## Índice de documentos

| Documento | Descripción | Estado |
| :--- | :--- | :--- |
| `Políticas/Politicas.md` | Normativa interna: gestión de datos sensibles, confidencialidad (NDA), propiedad intelectual y reglas de negocio. | Aprobado |
| `Directrices/Directrices.md` | Guías técnicas: estándares de codificación, control de versiones y documentación de código. | En revisión |
| `Planes/Planes.md` | Planificación: cronograma maestro, gestión de la configuración, aseguramiento de la calidad y gestión de riesgos. | Aprobado |

## Flujo de aprobación

Toda modificación de la documentación oficial debe proponerse mediante un Pull Request y ser validada por la Jefatura de Proyecto antes de su integración a la línea base.
