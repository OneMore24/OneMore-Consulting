# Directrices técnicas

Guías operativas para asegurar que el desarrollo de software mantenga un estándar de calidad y consistencia técnica.

## Estándares de ingeniería

- Código limpio: convenciones de estilo según el stack de cada proyecto (en ACA: TypeScript/React Native, Node.js y MySQL).
- Control de versiones: guía de Git Flow (nomenclatura de ramas y estructura de commits).
- Documentación de código: comentarios técnicos y elaboración de diccionarios de datos.

El detalle completo se encuentra en `Directrices.md`.
