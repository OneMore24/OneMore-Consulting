# Proyecto SADE — Sistema de Administración de Datos Empresariales

Cliente: Grupo Andino Comercial
Estado: Pendiente (firma de contrato).

## Requisitos

- Centralización del inventario de tres almacenes físicos.
- Alertas de stock mínimo.
- Generación automática de órdenes de compra a proveedores.

## Tecnologías

- Lenguaje: Java
- Base de datos: Oracle Database
- Arquitectura: MVC (Modelo-Vista-Controlador)

## Cronograma

- Inicio del proyecto: noviembre de 2026 (proyectado).
- Hito actual: firma del SLA y del contrato.
- Fecha de entrega estimada: febrero de 2027.
