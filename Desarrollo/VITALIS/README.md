# Proyecto VITALIS — Gestión de Historiales Clínicos

Cliente: Clínica San Gabriel
Estado: En desarrollo (implementación de la lógica central).

## Requisitos

- Módulo CRUD para las historias clínicas digitales de los pacientes.
- Sistema de triaje automático (priorización cuando la saturación de oxígeno sea inferior al 95 %).
- Asignación de turnos médicos en tiempo real.

## Tecnologías

- Backend: C++ (alta eficiencia y gestión de memoria)
- Base de datos: SQL Server
- Arquitectura: microservicios (proyección)

## Cronograma

- Inicio del proyecto: 5 de enero de 2026.
- Hito actual: pruebas unitarias del módulo de triaje.
- Fecha de entrega estimada: 15 de julio de 2026.
