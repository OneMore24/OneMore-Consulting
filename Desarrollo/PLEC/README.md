# Proyecto PLEC — Plataforma de Evaluación de Capacidades

Cliente: Corporación Talento
Estado: En desarrollo (fase de pruebas de integración).

## Requisitos

- Carga y validación de baterías de preguntas psicométricas.
- Motor de evaluación para el cálculo de puntajes y rankings.
- Exportación automática de reportes de candidatos en PDF.

## Tecnologías

- Backend: Python
- Base de datos: PostgreSQL
- Librerías adicionales: ReportLab (generación de PDF)

## Cronograma

- Inicio del proyecto: 10 de marzo de 2026.
- Hito actual: calibración del algoritmo de ranking.
- Fecha de entrega estimada: 10 de junio de 2026.
